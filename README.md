# Curiosity Lab

Web estática de experimentos interactivos originales, hecha con HTML, CSS y JavaScript sin frameworks ni dependencias.

## Incluye
- Diseño minimalista adaptable a móvil.
- **El efecto mariposa digital:** simulador con controles.
- **La máquina de casi nada:** experimento absurdo con resultados aleatorios.
- **¿Cuánto es un segundo?:** reto para probar tu percepción del tiempo.
- Ventanas modales, controles y navegación accesibles.

## Probarlo
1. Descomprime el ZIP.
2. Abre `index.html` en tu navegador. No necesitas instalar nada.

## Publicarlo gratis en GitHub Pages
1. Inicia sesión en [GitHub](https://github.com/).
2. Crea un repositorio público llamado `curiosity-lab`.
3. Sube `index.html`, `styles.css` y `script.js` a la raíz del repositorio.
4. Entra en **Settings → Pages**.
5. En **Build and deployment**, selecciona **Deploy from a branch**.
6. Elige la rama `main` y la carpeta `/ (root)`, y pulsa **Save**.
7. Espera unos minutos. GitHub mostrará el enlace publicado en esa sección. Normalmente será `https://TU-USUARIO.github.io/curiosity-lab/`.

Si el repositorio se llama exactamente `TU-USUARIO.github.io`, la URL será `https://TU-USUARIO.github.io/`.

## Personalizar
- Textos y tarjetas: `index.html`
- Colores, distribución y móvil: `styles.css`
- Lógica de los experimentos: `script.js`

GitHub Pages publica archivos estáticos. Si más adelante quieres cuentas, guardar datos entre usuarios o multijugador, necesitarás un backend o un servicio externo.
